# 생각 줄다리기 (tug-of-war)

질문 하나를 두고 학생이 근거 한 줄을 보내면, 고른 쪽과 당기는 세기(1 살짝 ~ 5 아주 세게)에 따라 줄 위에 카드가 놓이는 사고 가시화 도구입니다.

- 주소: https://plusiam.github.io/tug-of-war/
- 이전 버전(v1, 2026-11-12 오후판): https://plusiam.github.io/tug-of-war/v1/
- 통신 구조 변경 전 버전(v2, 2026-11-12 밤): https://plusiam.github.io/tug-of-war/v2/ (교사와 학생이 모두 같은 주소 버전을 써야 연결됩니다. 학생 주소는 교사 화면의 QR·접속 코드 창에 나오는 것을 쓰면 됩니다.)
- 선생님: 「줄다리기 판 만들기」 → 질문·양 끝 이름 입력 → 접속 코드·QR을 전자칠판에 띄우기
- 학생: QR 또는 접속 코드 4자리 → 번호·별명 → 근거 한 줄을 쓰고, 미니 밧줄 위 카드를 끌어(또는 버튼·슬라이더로) 쪽과 세기를 정해 보내기
- 공유 화면: 카드 끌어 옮기기, 여러 장 골라 묶기, 이름 보이기/숨기기, 숨기기
- 친구 근거 공유: 끄면(기본) 판에는 근거 글 없이 쪽(색)·세기(점)·쓴 사람(번호·별명)만 작은 표시로 보여 많은 인원도 겹치지 않습니다. 표시를 누르면 그 학생의 근거가 펼쳐집니다. 켜면 판에 근거 글이 보이고 학생 화면에도 친구 근거(이름 없이)와 공감 ♥가 나옵니다.
- 처음 생각 / 만약에 생각
  - 「그런데 만약에?」 전에는 처음 생각이 판 전체(줄 위·아래 번갈아)에 놓이고, 만약에를 띄우면 줄 위쪽으로 모입니다.
  - 「그런데 만약에?」를 띄우면 학생은 처음 생각마다 「그대로예요」 또는 「옮기기」로 만약에 생각을 보내고(새 근거도 가능), 만약에 생각은 줄 아래쪽에 놓입니다. 처음 생각은 지워지지 않고 흐리게 남습니다.
  - 카드를 누르면 같은 학생의 카드에 점선 테두리, 처음→만약에 연결에 화살표가 보입니다.
  - 만약에 카드에는 그대로 / 세기 바뀜 / 쪽 바뀜 / 새 근거 표시가 붙습니다. 「그대로」 카드는 글 없이 작은 표시(세기 점 + 그대로)로만 보이고, 누르면 펼쳐지며 처음 생각과 화살표로 이어집니다. 줄 가까이에는 바뀐 생각·새 근거가 먼저 놓입니다.
  - 새 만약에 질문을 띄우면 줄 아래는 새 질문의 생각으로 바뀌고, 앞선 카드는 내보내기에 남습니다. 「질문 내리기」를 하면 학생 입력이 처음 질문으로 돌아갑니다.
- 찬반 수: 기본은 숨김. 교사가 「찬반 수」를 누르면 처음 생각·만약에 생각의 쪽별 학생 수, 참여 수, 쪽이 바뀐/세기만 바뀐/그대로인 학생 수가 보입니다(학생마다 그 단계의 가장 최근 카드 1장 기준).
- 내보내기: 이미지(PNG), 표(CSV), 표 복사(AI·문서 붙여넣기). 단계, 이어진 처음 생각 번호, 변화, 학생 수 요약이 함께 들어갑니다. 이름을 숨기면 같은 학생에게 같은 「학생N」을 붙입니다.

학생 글은 서버에 저장하지 않습니다. Supabase Realtime 방송으로 선생님 화면에 전달만 되고, 선생님 기기(브라우저)에만 남습니다. 학생 기기에는 코드+이름별로 내가 보낸 근거가 남습니다.

## 통신 구조 (v3, 2026-11-12)

인원이 많아도(약 100명) 무료 한도 안에서 돌도록, 학생은 보내기만 하고 학생 메시지는 교사 화면만 받습니다.

- 학생 → 교사: 근거 카드·공감·입장 알림을 HTTP로 한 번 보냅니다. 다른 학생 기기에는 가지 않습니다.
- 교사 → 학생 한 명: 도착 확인과 처음 들어올 때의 판 설정은 그 학생에게만 갑니다.
- 교사 → 전체: 만약에 띄우기, 친구 근거 공유 켜기·끄기, 질문 고치기처럼 판이 바뀔 때만 모두에게 한 번 보냅니다.
- 친구 근거 공유를 켠 동안 학생 화면의 친구 근거 목록은 약 4초에 한 번 갱신됩니다(교사 판은 바로 바뀜).
- 2026-11-12 시험: 따로 접속한 학생 100명이 10초 안에, 또 3초 안에 100장을 보냈을 때 100장 모두 도착, 도착 확인 중앙값 약 0.3초, 끊김 0건. 한 PC의 브라우저에서 100개 연결을 만든 시험이며, 실제 기기 100대·학교 무선망 시험은 아닙니다.
- 한도(Supabase 무료): 동시 접속 200, 초당 메시지 100. cbc-share와 같은 프로젝트를 씁니다.
