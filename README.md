## 2026-11-13: 한 수업 코드, 여러 질문판

- 처음 수업을 만들면 접속코드 하나가 생깁니다. 학생은 코드와 번호/별명으로 들어갑니다.
- **새 질문판**은 이전 질문과 결과를 지우지 않고 빈 질문판을 추가합니다. 추가만으로 학생 화면은 바뀌지 않습니다.
- **질문판 목록**에서 이전 판을 열람할 수 있습니다. 교사 열람판과 학생 진행판은 별개입니다.
- 학생에게 제시할 판에서 **이 질문 시작**을 눌러야 학생 화면이 바뀝니다. 수업 안에서는 접속코드를 다시 입력하지 않습니다.
- 학생이 쓰던 초안과 수정 중인 카드는 질문판별로 이 기기에 보관됩니다. 늦은 응답도 원래 질문판에 들어갑니다.
- **보관한 수업 목록**에는 이전 수업들이 표시됩니다. 새 질문판 생성은 기록 삭제가 아닙니다.
- 기존 코드별 판은 첫 질문판으로 자동 이관하며, 기존 원본 저장값은 보존합니다. 구버전(v1/v2/next)과 현재판을 같은 수업 코드로 동시에 운영하지 마세요.

## JSON 저장과 불러오기

- **수업 저장(JSON)**은 모든 질문판, 학생 번호/별명, 숨긴 카드, 묶음, 배치, 처음/만약에 단계 및 수정 이력을 포함한 교사 비공개 백업입니다. 이름 표시를 꺼도 백업에는 실제 입력한 번호/별명이 들어갑니다. 파일은 암호화되지 않으므로 학생이나 공개 게시판에 공유하지 마세요.
- **저장한 수업 불러오기**에서 JSON을 선택하면 질문 제목, 질문판/카드 수, 저장 시각을 확인할 수 있습니다. 파일 검증이 끝나기 전에는 기존 자료를 변경하지 않습니다.
- 가져온 수업은 새 보관 사본으로 열립니다. 원본은 덮어쓰지 않으며, 처음에는 실시간 연결 없는 오프라인 열람입니다.
- 학생과 다시 활동하려면 **수업 재개**를 눌러 새 코드를 발급합니다. 새 코드에서는 학생이 새로 입장해야 하며, 교사 백업만으로 학생 새 기기의 개인 기록까지 복원되지는 않습니다. 같은 별명을 쓴다고 과거 학생 신원과 자동 병합하지 않습니다.
- 전용 JSON 형식(version 4), 최대 10MB만 지원합니다. CSV는 결과 공유용 표이므로 수업 복원 파일로 사용할 수 없습니다.

## 다시 놓기와 근거 수정

- 현재 쪽은 기존 파랑/빨강으로 표시합니다.
- 같은 단계에서 쪽이나 세기가 실제로 달라졌으면 보라색 보조 띠와 **↔ 다시 놓음**을 표시합니다. 원래 자리로 돌아온 경우에도 이동 이력이 남습니다.
- 글만 바뀌었으면 **근거 수정**을 표시합니다. 무수정 재전송과 통신 재시도는 변화로 세지 않습니다. 교사가 화면에서 카드를 정리해 옮긴 것도 학생의 생각 변화로 세지 않습니다.
- 카드를 선택했을 때만 이전 위치의 빈 표식과 이동 경로가 보입니다. 카드가 많아도 모든 이동선이 항상 겹치지 않도록 했습니다.
- 이 표시는 수정 사실을 기록하는 것이며, 생각을 바꾼 학생이 더 잘했다는 뜻이 아닙니다.

## 한 질문 안의 처음 생각 / 만약에 생각

- **그런데 만약에?**는 별도의 다음 질문판이 아니라 같은 질문에서 근거의 힘을 다시 살펴보는 단계입니다.
- 처음 생각은 줄 위에 남고, 학생은 **그대로예요** 또는 **옮기기**로 만약에 생각을 보냅니다. 새 근거도 보낼 수 있습니다.
- 카드를 선택하면 같은 학생의 처음/만약에 연결을 확인할 수 있습니다. 그대로/세기 바뀜/쪽 바뀜/새 근거 표시는 단계 간 비교입니다.
- 친구 근거 공유는 기본 꺼짐입니다. 꺼지면 번호·쪽·세기만 보이고, 선택한 근거를 펼쳐 볼 수 있습니다. 켜짐/꺼짐이 버튼에 표시되며 끌 때 선택도 해제됩니다.
- 찬반 수는 기본 숨김입니다. 다수결로 승패를 정하는 기능이 아닙니다.

## 결과 공유와 개인정보

- 기존 **내보내기**: PNG 이미지, CSV 표, 표 복사. 이름 숨김 상태의 표에는 학생1·학생2처럼 일관된 별칭을 사용합니다.
- 학생 글은 서버 DB에 저장하지 않습니다. Realtime으로 전달되고 교사와 해당 학생 브라우저에 남습니다.
- 공용 기기에서는 교사 비공개 JSON을 안전하게 보관한 뒤 브라우저의 사이트 데이터를 지우세요. 사이트 데이터 삭제는 브라우저에 있는 다른 수업 기록도 지우므로 먼저 백업을 확인하세요.

## 통신과 버전

- 기존 v3의 학생 HTTP 송신, 교사 수신 구독 구조를 유지합니다. 새 DB나 유료 서비스는 추가하지 않았습니다.
- 질문판 식별자와 설정 순번으로 응답·도착 확인·재전송을 분리합니다. 교사는 열람판과 무관하게 진행판 설정을 학생에게 보냅니다.
- 업데이트 후 교사와 학생 화면을 모두 새로고침하세요. 구버전 학생은 다음 질문판에서 새로고침 안내를 봅니다.
- 접속코드 충돌 검사는 기존 실시간 확인 방식이며 서버의 원자적 예약은 아닙니다.
- /v1/, /v2/는 이전 대체판, /next/는 기존 두 서버 사전시험판으로 보존합니다. 이번 다중 질문판/JSON 변경은 루트에 반영합니다. /next/를 루트로 자동 승격하지 않습니다.
- 이전 버전의 100/275명 시험은 그 버전에 대한 기록이며, 이번 기능의 실제 학생 기기 다수·학교 무선망 시험을 의미하지 않습니다.
