# 생각 줄다리기 (tug-of-war)

질문 하나를 두고 학생이 근거 한 줄을 보내면, 고른 쪽과 당기는 세기(1~5)에 따라 줄 위에 카드가 놓이는 사고 가시화 도구입니다.

- 주소: https://plusiam.github.io/tug-of-war/
- 선생님: 「줄다리기 판 만들기」 → 질문·양 끝 이름 입력 → 접속 코드·QR을 전자칠판에 띄우기
- 학생: QR 또는 접속 코드 4자리 → 번호·별명 → 근거 한 줄, 쪽, 세기를 정해 보내기
- 공유 화면: 카드 끌어 옮기기, 여러 장 골라 묶기, 이름 보이기/숨기기, 숨기기
- 그런데 만약에?: 생각을 흔드는 질문을 띄우면 학생이 근거를 다시 놓을 수 있고 옮긴 기록이 남음
- 내보내기: 이미지(PNG), 표(CSV), 표 복사(AI·문서 붙여넣기)

학생 글은 서버에 저장하지 않습니다. Supabase Realtime 방송으로 선생님 화면에 전달만 되고, 선생님 기기(브라우저)에만 남습니다.
