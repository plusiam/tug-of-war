## 2026-11-13: 한 수업 코드, 여러 질문판

- 처음 수업을 만들면 접속코드 하나가 생깁니다. 학생은 코드와 번호/별명으로 들어갑니다.
- **새 질문판**은 이전 질문과 결과를 지우지 않고 빈 질문판을 추가합니다. 추가만으로 학생 화면은 바뀌지 않습니다.
- **질문판 목록**에서 이전 판을 열람할 수 있습니다. 교사 열람판과 학생 진행판은 별개입니다.
- 학생에게 제시할 판에서 **이 질문 시작**을 눌러야 학생 화면이 바뀝니다. 수업 안에서는 접속코드를 다시 입력하지 않습니다.
- 학생이 쓰던 초안과 수정 중인 카드는 질문판별로 이 기기에 보관됩니다. 늦은 응답의 동일 ID·리비전 재시도는 확인하지만, 이미 끝난 질문판·단계의 신규/수정 응답은 받지 않고 초안을 보관합니다.
- **보관한 수업 목록**에는 이전 수업들이 표시됩니다. 새 질문판 생성은 기록 삭제가 아닙니다.
- 기존 코드별 판은 첫 질문판으로 자동 이관하며, 기존 원본 저장값은 보존합니다. 구버전(v1/v2/next)과 현재판을 같은 수업 코드로 동시에 운영하지 마세요.

## 질문판 삭제와 복원

- **질문판 목록 → 삭제 → 질문 제목과 카드 수 확인 → 휴지통으로 이동** 순서입니다. 실제 사용자 기록을 자동으로 삭제하지 않습니다.
- 진행 중인 질문판과 마지막 남은 질문판은 삭제할 수 없습니다. 진행 중인 판은 다른 질문을 먼저 시작한 뒤 삭제하세요.
- 삭제는 영구 삭제가 아니라 목록에서 숨겨 휴지통에 보관하는 동작입니다. **질문판 목록 → 휴지통 → 복원**으로 응답과 이력을 되살릴 수 있습니다. 복원해도 학생 질문은 자동으로 바뀌지 않습니다.
- 휴지통의 질문판도 교사 비공개 JSON에 포함됩니다. 기존 JSON 백업도 계속 불러올 수 있습니다.

## 학생 화면: 근거 작성과 전송

- 밧줄과 자리 선택 아래에 근거 작성과 보내기를 한 영역으로 모았습니다. 근거부터 쓰거나 자리부터 골라도 됩니다.
- 친구 근거가 없을 때는 안내 문구와 빈 영역을 표시하지 않습니다. 교사가 공유를 켰고, 현재 질문판·단계에 내 것을 제외한 근거가 있을 때만 자동으로 나타납니다. 공유를 끄거나 표시할 근거가 없어지면 다시 숨깁니다.
- 미니 밧줄 드래그는 유지합니다. 기존 쪽 버튼과 세기 슬라이더는 **버튼으로 쪽·세기 조절**을 펼쳐 사용할 수 있습니다.
- 근거는 2줄 입력창이며 60자 제한을 유지합니다. Enter는 줄바꿈이고 전송은 **보내기/이번 생각 수정 보내기** 버튼으로만 합니다.
- 버튼 가까이에서 부족한 항목, 선택한 자리, 전송 중, 도착, 실패 상태를 안내합니다.
- 전송 중인 같은 제출은 중복 발송하지 않습니다. 도착 확인 뒤에만 안전하게 입력을 비우며, 기다리는 동안 새로 고친 글이나 다른 질문판의 초안은 지우지 않습니다.
- 실패하거나 도착 확인을 받지 못한 경우 글과 자리를 유지해 다시 보낼 수 있습니다. 재시도는 같은 카드 기록을 사용합니다.
- 브라우저 화면 크기 시험은 실제 휴대폰 키보드/Safari 시험과 다릅니다. 실기기에서 키보드 가림 여부를 별도 확인해야 합니다.

### 학생 화면에서 질문이 먼저 보이게 (2026-11-14)

- 질문을 남색 카드에 흰 글씨로 보여 주고 작은 이름표 「질문」을 붙였습니다. 색은 양쪽 끝(파랑·빨강)과 만약에(노랑)에 쓰지 않는 남색만 씁니다. 줄은 낱말 단위로 바뀌고, 30자가 넘는 질문은 글자를 조금 줄입니다.
- **그런데 만약에?**가 떠도 처음 질문의 글자 크기를 줄이지 않습니다. 처음 질문을 중심으로 두고 추가 질문을 아래에 들여써 위계를 보여 줍니다. 원래 질문은 지우거나 흐리게 하지 않습니다.
- 근거 칸 바로 위에 처음 질문과 현재 추가 질문을 함께 보여 줍니다. 긴 문장도 임의로 생략하지 않습니다. 화면에 고정하지 않고 문서 흐름 안에 두어, 근거 칸과 함께 볼 수 있습니다.
- 높이를 되찾기 위해 학생 화면의 패널 제목을 20→18px, 휴대폰의 위쪽 여백을 28→16px로 줄였습니다. 그래도 근거 칸은 이전보다 약 80px(만약에 단계 약 100px) 아래에 놓입니다.
- 학생 화면의 모양만 바꿨습니다. 저장 형식(ROOM_VERSION 4)·통신 규칙·교사 화면은 그대로입니다. 기존 자동 시험 229개 통과. 휴대폰 크기 에뮬레이션(390·320px)으로만 확인했고 실제 휴대폰에서는 확인하지 못했습니다.

### 처음 질문·추가 질문의 위계와 현재 응답 (2026-11-14)

- **처음 질문**을 중심 질문으로 표시합니다. 학생 화면은 24px(30자가 넘으면 21px)을 유지하고 추가 질문은 20px로, 교사 화면은 26px/20px(폰은 22px/18px)로 구분합니다. 가로 폰은 18px/16px입니다.
- **추가 질문 N**은 처음 질문 아래에 16px 들여써 연결합니다. 추가 질문은 새 중심 질문이 아니라 처음 질문을 다시 생각해 볼 조건임을 짧게 안내합니다.
- 학생에게 **지금 답할 질문**, 교사에게 **학생이 지금 답할 질문**을 표시합니다. 처음에는 처음 질문에, 추가 질문이 시작되면 그 추가 질문에 배지를 붙입니다. 보관판·오프라인에는 현재 응답 배지를 붙이지 않습니다.
- 교사 질문 묶음은 관리 도구 줄보다 위에 놓습니다. 교사가 지난 회차 카드를 보고 있어도 위쪽 배지는 현재 학생에게 제시된 질문을 가리키며, 지난 회차 열람은 기존 회차 표시줄로 구분합니다.
- 학생 입력 제목은 **처음 질문에 답하기 / 추가 질문 N에 답하기**이며, 보낸 뒤에는 해당 질문의 생각 수정임을 표시합니다. 입력칸 위에도 처음 질문과 현재 추가 질문(회차 포함)을 다시 보여 줍니다.
- **질문 내리기**로 입력이 잠기면 **응답 잠시 멈춤**으로 바뀌고 현재 답할 질문 배지를 없앱니다. 처음 질문이 다시 수정 가능해졌다는 오해를 막습니다.
- 화면 표시만 변경했습니다. 한 사람·한 회차 한 장, 초안·도착 확인·재전송·저장 형식(JSON v4)·통신 규칙은 그대로입니다. 회귀 288개 + 표시 시험 25개, 총 313개 통과.
- 320/390px 폰 폭, 교사 824px, 가로 폰 모의 화면 및 긴 질문을 확인했습니다. 실제 아이폰·안드로이드·인앱 브라우저는 미확인입니다. 질문을 생략하지 않는 만큼 긴 문장에서는 세로 스크롤이 늘 수 있습니다.

## 응답 잠시 멈추기와 다시 받기 (2026-11-14)

**문제**: 추가 질문을 띄운 뒤 「질문 내리기」를 누르면 모든 학생 입력이 닫혔는데(처음 질문에 아직 답하지 않은 학생 포함), 되돌리는 단추가 없었습니다. 새 추가 질문을 띄워야만 풀렸고, 그러면 번호가 하나 늘고 같은 질문을 다시 쓰면 학생이 같은 질문을 두 번 받았습니다. 또 잘못 띄운 질문을 내린 뒤 지우면 판이 계속 멈춘 채로 남았습니다. 학생 화면에는 「이전 생각 · 읽기 전용」이라고만 나와 고장처럼 보였습니다.

**고친 것**
- 「질문 내리기」 단추 이름을 실제 동작대로 **「응답 잠시 멈추기」**로 바꿨습니다(「그런데 만약에?」 창 안).
- **「응답 다시 받기」**를 추가했습니다. 내려 둔 질문을 번호 그대로 다시 올립니다. 새 질문을 만들지 않으므로 번호가 늘지 않고, 학생은 멈추기 전 자기 차례의 질문부터 이어 갑니다. 쓰던 글과 고른 쪽·세기도 그대로입니다.
  - 멈춰 있는 동안 교사 판의 질문 바로 아래에 「응답 잠시 멈춤 · 학생들이 지금은 답을 보낼 수 없어요」와 함께 이 단추가 보입니다(넓은 화면·휴대폰 교사 화면 모두, 추가 질문을 가려 둔 상태에서도). 「그런데 만약에?」 창에도 같은 단추가 있습니다.
  - 진행 중인 질문판에서만 됩니다. 보관판·오프라인 사본에는 단추가 없습니다.
- **띄웠던 추가 질문을 모두 지운 판은 잠기지 않습니다.** 추가 질문을 띄운 적 없는 판처럼 처음 질문을 다시 받습니다(카드가 한 장도 없는 질문만 지울 수 있으므로 처음 생각과 비교할 답이 없는 경우입니다). 지운 번호는 여전히 재사용하지 않습니다.
- 학생 화면은 멈춘 동안 「응답 잠시 멈춤 · 선생님이 다시 열면 보낼 수 있어요. 쓰던 글은 보관돼요」로 알려 줍니다. 처음 답을 아직 보내지 않은 학생에게도 맞는 말입니다.
- 멈춘 동안 도착한 카드는 예전처럼 받지 않고, 거부 사유를 멈춤으로 알려 줍니다.

**그대로인 것**: 저장 형식(ROOM_VERSION 4), 통신 필드, 번호 규칙(당기거나 재사용하지 않음), 멈춘 동안 처음 생각을 고칠 수 없다는 규칙.

**되돌릴 때 주의**: 「응답 다시 받기」를 쓴 뒤에는 저장된 수업의 `whatif` 배열 끝에 지운 빈 칸(`''`)이 올 수 있습니다(뒤쪽 질문을 지운 판에서만). 이 커밋 이전 코드로 되돌리면 그런 판을 "멈춤"으로 잘못 표시합니다. 되돌려야 하면 그 판에서 새 추가 질문을 하나 띄우면 정상으로 읽힙니다.

**확인**: 자동 시험 459개(기존 419 + 멈춤·다시 받기 40) 통과, 독립 코드 검토에서 배포를 막을 결함 없음, PC 브라우저에서 실제 Realtime 연결로 교사 판(넓은 화면·폰 폭)과 학생 2명(먼저 답한 학생, 멈춘 동안 들어온 학생) 흐름 확인. 실제 휴대폰·전자칠판은 확인하지 못했습니다.

## 넓은 화면 교사 도구 줄 정리 (2026-11-14)

PC·전자칠판 교사 화면의 도구 줄에 단추가 15개(폭 824px에서 두 줄)여서 수업 중 누르는 것만 줄에 남기고 나머지는 자리를 옮겼습니다. 없앤 기능은 없습니다.

- **줄에 항상 보이는 것**: 질문판 목록 · 이 질문 시작 · 친구 근거 · 그런데 만약에? · 크게 보기 · 보기 설정 ▾ · 저장·내보내기 · ⋯
- **보기 설정 ▾** (단추 아래로 펼쳐지는 작은 패널): 추가 질문 가리기, 찬반 수, 이름 보이기, 글자 크기(가- 가+). 패널 안 단추를 눌러도 닫히지 않아 판을 보면서 연달아 고칠 수 있고, 패널 밖을 누르거나 Esc로 닫습니다.
- **저장·내보내기** (창): 내보내기, 수업 저장(JSON), 저장한 수업 불러오기.
- **새 질문판**은 도구 줄에서 뺐습니다. 「질문판 목록」 창 안과 「⋯」 안에 그대로 있습니다.
- 보고 있는 질문판이 이미 진행 중이면 「진행 중인 질문」을 단추가 아닌 글자로 보여 줍니다. 다른 질문판을 볼 때만 「이 질문 시작」 단추가 나타납니다.
- 추가 질문을 가렸을 때의 안내 문구 등 단추 위치를 가리키던 글을 새 자리에 맞게 고쳤습니다.
- 켜진 설정 개수를 묶음 단추에 숫자로 붙이지 않습니다. 가림 안내 상자, 찬반 수 줄, 카드의 이름처럼 판 자체가 상태를 보여 주기 때문입니다.
- 휴대폰 교사 화면(폭 640px 이하·가로 폰)은 그대로입니다. 저장 형식(ROOM_VERSION 4), 통신, 학생 화면도 바뀌지 않았습니다.
- 확인: 기존 자동 시험 419개 통과, PC 브라우저에서 폭 1920·1366·1024·824·700·390px과 실제 Realtime 연결로 동작 확인. 실제 전자칠판 터치는 확인하지 못했습니다.
- 되돌릴 때는 이 커밋 하나만 되돌리면 됩니다(바로 앞 465ded9).

## 휴대폰으로 교사 역할 하기 (2026-11-13)

- 창 폭이 640px 이하이면 교사 화면이 휴대폰용으로 바뀝니다. 위에는 칸별 카드 수를 보여 주는 요약 밧줄, 아래에는 근거 카드가 한 줄씩 세로로 놓여 겹치지 않습니다. PC·전자칠판의 밧줄 판은 그대로입니다.
- 휴대폰 도구 줄에는 **이 질문 시작**, **친구 근거 켜짐/꺼짐**, **그런데 만약에?**, **⋯**만 보입니다. 질문판 목록, 새 질문판, JSON 저장·불러오기, 이름 보이기, 찬반 수, 내보내기는 **⋯** 안에 있습니다.
- 카드 끌어 옮기기와 묶기는 큰 화면 전용입니다. 휴대폰에서는 줄을 눌러 펼친 뒤 숨기기만 할 수 있습니다.
- **접속 코드**를 누르면 QR과 코드가 화면 가득 뜹니다. 옆 사람에게 휴대폰을 보여 주세요.
- 교사 화면은 수업 중 화면이 꺼지지 않게 요청하고, 다른 앱에 다녀오면 다시 연결해 학생에게 현재 질문을 다시 보냅니다. 브라우저가 화면 꺼짐 방지를 지원하지 않으면 휴대폰 자동 잠금을 길게 설정해 주세요.
- 교사 화면이 꺼져 있던 동안 학생이 보낸 근거는 교사가 돌아오면 자동으로 다시 전송됩니다(카드당 3회까지, 그 뒤에는 학생이 **재전송**을 누릅니다).
- 교사 역할을 마치고 학생으로 바꿀 때는 **⋯ → 수업 닫고 처음 화면으로**를 누릅니다. 기록은 이 기기에 남고 **이어서 열기**로 다시 열 수 있습니다. 교사 화면을 닫으면 그 수업의 학생 연결은 끊깁니다.
- 방을 만들 때 접속 코드가 다른 수업과 겹치는지 한 번 더 확인합니다. 동시에 만들어 겹치면 나중에 만든 쪽이 자동으로 새 코드를 받습니다. 학생은 입장 뒤 질문이 우리 모둠 것인지 확인해 주세요.
- 연수처럼 여러 모둠이 동시에 쓸 때는 모둠당 한 명만 방을 만들고, 교사 휴대폰으로 학생 역할을 겸하지 않는 편이 안전합니다. 전원 접속 수가 무료 한도에 가까우면 그 기간만 요금제를 올려야 합니다.
- 화면 크기 모의시험과 모형 통신으로 확인했습니다. 실제 휴대폰 여러 대, 화면 잠금 복귀, 행사장 무선망 시험은 별도로 해야 합니다.

### 만약에 뒤 변화 보기 · 휴대폰 가로 (2026-11-14)

- 휴대폰 목록의 **만약에 생각**은 처음 생각과 달라진 카드부터 놓입니다: 쪽 바뀜 → 세기 바뀜 → 새 근거 → 그대로. 접거나 거르지 않으므로 그대로인 근거도 모두 남습니다.
- **찬반 수**의 변화 줄은 카드 표시와 같은 기준으로 셉니다. 학생마다 처음 생각과 이어진 카드를 먼저 고릅니다. 신규 응답은 단계별 한 장을 수정하므로 같은 단계에서 새 카드가 늘어나지 않습니다. 이전 버전의 다중 카드는 그대로 보관하고 기존 학생별 집계 기준을 유지합니다. 새 근거만 쓴 학생과 아직 안 보낸 학생은 따로 보여 줍니다. CSV·표 복사의 요약 줄도 같습니다.
- 휴대폰을 가로로 돌려도 목록 화면이 유지됩니다(왼쪽 요약 밧줄, 오른쪽 목록). 기기 화면의 짧은 변이 500px 이하이고 손가락으로 쓰는 화면일 때만 해당하므로 태블릿·노트북·전자칠판의 밧줄 판은 그대로입니다.
- 가로 판정은 화면 크기 흉내로만 확인했습니다. 실제 휴대폰 두세 종에서 가로로 돌려 확인해야 합니다.

### 만약에 질문 고치기·지우기 (2026-11-14)

- **그런데 만약에?** 창의 「지금까지 띄운 질문」에서 줄마다 카드 수가 보이고, **고치기**로 질문 글을 고칠 수 있습니다. 떠 있는 질문을 고치면 학생 화면의 문구도 바뀌고, 학생이 쓰던 글과 보낸 카드는 그대로입니다. 이미 카드가 있는 질문은 오탈자만 고쳐 주세요. 고치기 전 글은 남지 않습니다.
- 잘못 띄운 질문은 **지우기**로 지울 수 있습니다. 카드가 한 장도 없고(숨긴 카드 포함) 지금 떠 있지 않은 질문만 지울 수 있습니다. 떠 있는 질문은 먼저 「응답 잠시 멈추기」(예전 이름 「질문 내리기」)를 해 주세요.
- 지워도 **남은 질문의 번호는 그대로**입니다(1번을 지우면 2번은 계속 2번). 카드와 학생 기기는 질문을 번호로 기억하기 때문에, 번호를 당기면 학생이 다시 보낸 카드가 거부되거나 다른 질문의 답으로 들어갑니다. 새로 띄우는 질문도 지운 번호를 다시 쓰지 않고 다음 번호를 받습니다.
- 진행 중이 아닌 질문판을 보는 동안에는 질문을 띄울 수 없습니다. 그 질문은 학생에게 전달되지 않기 때문입니다. 「이 질문 시작」을 누른 뒤에 띄워 주세요. 고치기·지우기·내리기는 어느 질문판에서나 됩니다.
- 저장 형식(JSON)은 바뀌지 않았습니다. 지운 질문은 글이 빈 칸으로 저장됩니다.

### 지난 만약에 질문 다시 보기 (2026-11-14)

- 만약에 질문이 둘 이상이면 판 위쪽에 **만약에 질문** 번호 줄이 생깁니다(휴대폰에서는 요약 밧줄 안의 번호 칩). 번호를 누르면 그 질문의 카드가 줄 아래에 놓이고, 번호 옆 작은 글자는 그 질문의 카드 수입니다.
- 기본은 가장 최근 질문입니다. 지난 질문을 보는 동안에는 「지난 질문을 보는 중이에요」와 **최신으로** 버튼이 보이고, 새 카드가 들어와도 보던 질문에 머뭅니다. 새 질문을 띄우면 최신으로 돌아갑니다.
- 어느 질문을 보든 비교 기준은 처음 생각입니다(그대로·세기 바뀜·쪽 바뀜·새 근거). 「찬반 수」도 보고 있는 질문 기준으로 바뀝니다.
- 보기만 바꾸는 기능입니다. 학생 화면과 저장되는 자료는 달라지지 않고, 내보내기(CSV·표 복사)의 요약 줄은 언제나 가장 최근 질문 기준입니다. 지운 질문은 번호 줄에 나오지 않습니다.

## JSON 저장과 불러오기

- **수업 저장(JSON)**은 모든 질문판, 학생 번호/별명, 숨긴 카드, 묶음, 배치, 처음/만약에 단계 및 수정 이력을 포함한 교사 비공개 백업입니다. 이름 표시를 꺼도 백업에는 실제 입력한 번호/별명이 들어갑니다. 파일은 암호화되지 않으므로 학생이나 공개 게시판에 공유하지 마세요.
- **저장한 수업 불러오기**에서 JSON을 선택하면 질문 제목, 질문판/카드 수, 저장 시각을 확인할 수 있습니다. 파일 검증이 끝나기 전에는 기존 자료를 변경하지 않습니다.
- 가져온 수업은 새 보관 사본으로 열립니다. 원본은 덮어쓰지 않으며, 처음에는 실시간 연결 없는 오프라인 열람입니다.
- 학생과 다시 활동하려면 **수업 재개**를 눌러 새 코드를 발급합니다. 새 코드에서는 학생이 새로 입장해야 하며, 교사 백업만으로 학생 새 기기의 개인 기록까지 복원되지는 않습니다. 같은 별명을 쓴다고 과거 학생 신원과 자동 병합하지 않습니다.
- 전용 JSON 형식(version 4), 최대 10MB만 지원합니다. CSV는 결과 공유용 표이므로 수업 복원 파일로 사용할 수 없습니다.

## 다시 놓기와 근거 수정

- 현재 쪽은 기존 파랑/빨강으로 표시합니다.
- 같은 단계에서 쪽이나 세기가 실제로 달라졌으면 보라색 보조 띠와 **↔ 다시 놓음**을 표시합니다. 원래 자리로 돌아온 경우에도 이동 이력이 남습니다.
- 글만 바뀌었으면 **근거 수정**을 표시합니다. 무수정 재전송과 통신 재시도는 변화로 세지 않습니다. 교사가 화면에서 카드를 정리해 옮긴 것도 학생의 생각 변화로 세지 않습니다.
- 카드를 선택했을 때만 이전 위치의 빈 표식과 이동 경로가 보입니다. 카드가 많아도 모든 이동선이 항상 겹치지 않도록 했습니다.
- 이 표시는 수정 사실을 기록하는 것이며, 생각을 바꾼 학생이 더 잘했다는 뜻이 아닙니다.

## 한 질문 안의 처음 생각 / 만약에 생각

- **그런데 만약에?**는 별도의 다음 질문판이 아니라 같은 질문에서 근거의 힘을 다시 살펴보는 단계입니다.
- 처음 생각은 줄 위에 남고, 현재 회차에서 앞선 생각을 그대로 보내거나 이번 생각을 수정합니다. 근거 변경도 같은 회차 한 장에 반영합니다.
- 카드를 선택하면 같은 학생의 처음/만약에 연결을 확인할 수 있습니다. 그대로/세기 바뀜/쪽 바뀜/새 근거 표시는 단계 간 비교입니다.
- 친구 근거 공유는 기본 꺼짐입니다. 꺼지면 번호·쪽·세기만 보이고, 선택한 근거를 펼쳐 볼 수 있습니다. 켜짐/꺼짐이 버튼에 표시되며 끌 때 선택도 해제됩니다.
- 찬반 수는 기본 숨김입니다. 다수결로 승패를 정하는 기능이 아닙니다.

## 결과 공유와 개인정보

- 기존 **내보내기**: PNG 이미지, CSV 표, 표 복사. 이름 숨김 상태의 표에는 학생1·학생2처럼 일관된 별칭을 사용합니다.
- 학생 글은 서버 DB에 저장하지 않습니다. Realtime으로 전달되고 교사와 해당 학생 브라우저에 남습니다.
- 공용 기기에서는 교사 비공개 JSON을 안전하게 보관한 뒤 브라우저의 사이트 데이터를 지우세요. 사이트 데이터 삭제는 브라우저에 있는 다른 수업 기록도 지우므로 먼저 백업을 확인하세요.

## 통신과 버전

- 기존 v3의 학생 HTTP 송신, 교사 수신 구독 구조를 유지합니다. 새 DB나 유료 서비스는 추가하지 않았습니다.
- 질문판 식별자와 설정 순번으로 응답·도착 확인·재전송을 분리합니다. 교사는 열람판과 무관하게 진행판 설정을 학생에게 보냅니다.
- 업데이트 후 교사와 학생 화면을 모두 새로고침하세요. 구버전 학생은 다음 질문판에서 새로고침 안내를 봅니다.
- 접속코드 충돌 검사는 기존 실시간 확인 방식이며 서버의 원자적 예약은 아닙니다.
- /v1/, /v2/는 이전 대체판, /next/는 기존 두 서버 사전시험판으로 보존합니다. 이번 다중 질문판/JSON 변경은 루트에 반영합니다. /next/를 루트로 자동 승격하지 않습니다.
- 이전 버전의 100/275명 시험은 그 버전에 대한 기록이며, 이번 기능의 실제 학생 기기 다수·학교 무선망 시험을 의미하지 않습니다.

## 단계별 한 사람 한 카드 (이번 구현, 미배포)

- 처음 쪽·세기·근거를 한 카드로 보내고, 교사가 추가하는 만약에 회차마다 한 장씩 보냅니다. 현재 회차는 **이번 생각 수정**으로 같은 카드의 리비전/이력을 갱신합니다. 입력 비우기·도착 확인·재접속으로 새 카드가 생기지 않습니다.
- 추가 질문이 한 번이라도 시작되면 처음 생각은 읽기 전용입니다. 다음 회차가 시작되면 이전 회차도 읽기 전용이며, 질문 내리기는 입력 일시중지입니다. stage=0이어도 archive 포함 질문 전체 길이로 initialLocked를 보내 처음 편집을 다시 열지 않습니다.
- 첫 만약에의 그대로는 처음 생각을, 이후 회차의 **앞선 생각 그대로**는 가장 최근 이전 회차의 응답을 복사합니다. from은 항상 최신 처음 카드로 연결하므로 모든 회차는 처음과 비교합니다. 직접 작성도 자동 연결합니다. 처음 기록 없이 늦게 들어온 학생은 현재 회차만 답하며 처음을 자동 생성하지 않습니다. 이때 from=null, 기존 새 근거 분류(처음 비교 없음)이며 변화·유지로 세지 않습니다.
- 교사 수신에서도 sid+질문판+단계당 신규 카드는 한 장만 허용합니다. 종료 단계의 높은 리비전은 거부하되 저장된 ID·리비전·본문·쪽·세기가 정확히 같은 재전송은 종료 후에도 ACK합니다. 같은 리비전으로 다른 내용을 보내면 ACK하지 않습니다.
